## TL;DR

GCP Cloud IDS is an intrusion detection system powered by Palo Alto Networks. Security Command Center is GCP's unified security and risk management platform. Cloud IDS costs $1.25/hour per endpoint. Security Command Center Premium is $25,000/year.

---

## What Is It?

### Cloud IDS
Managed network-based threat detection using Palo Alto technology.

### Security Command Center
Unified security and risk management for GCP.

---

## Pricing

| Component | Price |
|-----------|-------|
| **Cloud IDS** | $1.25/hour (~$900/month) |
| **Security Command Center Standard** | Free |
| **Security Command Center Premium** | $25,000/year |
